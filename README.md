# Elite Cars - Stock — подбор новых автомобилей в Кыргызстане

Информационно-продающий сайт: подбор и покупка новых автомобилей в наличии в Кыргызстане — поиск по дилерам
и импортёрам, проверка перед покупкой, торг, оформление, передача в Бишкеке или доставка по ЕАЭС.

Стек: **Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · Vercel Blob**.

## Запуск

```bash
npm install
cp .env.example .env.local   # заполните переменные (минимум ADMIN_PASSWORD)
npm run dev                  # http://localhost:3000
```

## Деплой на Vercel

1. Import Project → выберите этот репозиторий (Framework: Next.js, настройки по умолчанию).
2. **Storage → Create → Blob** → подключите хранилище к проекту. Переменная `BLOB_READ_WRITE_TOKEN` добавится сама.
3. **Settings → Environment Variables**: `ADMIN_PASSWORD` (пароль от админки), `NEXT_PUBLIC_SITE_URL` (домен сайта),
   при желании `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` для заявок.
4. **Redeploy**, чтобы переменные применились.

## Админ-панель — `/admin`

Вход по паролю из `ADMIN_PASSWORD`. Сейчас в админке — блок главной страницы **«Что мы привозим чаще всего»**:

- добавление, редактирование и удаление автомобилей (марка, модель, плашка, до 3 особенностей, цена «от», фото, ссылка);
- изменение порядка карточек стрелками;
- «Сбросить к стандартным» — вернуть 6 автомобилей из каталога.

Данные и фото хранятся в Vercel Blob (`featured-cars/`). Большие фото уменьшаются в браузере перед загрузкой.
Главная обновляется сразу после сохранения. Пока в админке ничего не сохраняли, показываются первые 6 моделей
каталога. Локально без Blob данные пишутся в папку `.data/` (она в `.gitignore`).

## Что заменить перед публикацией

Все бренд-данные — в `lib/site.ts`:

| Поле | Что указать |
| --- | --- |
| `name`, `legalName`, `tagline` | Название компании |
| `url` | Домен сайта (или переменная `NEXT_PUBLIC_SITE_URL`) |
| `contacts.*` | Телефон, WhatsApp, Telegram, email, адрес, часы работы |
| `social.*` | Ссылки на соцсети (пустое поле — ссылка скрыта на сайте) |
| `stats` | Цифры на главной |

Логотип — `public/logo-wide.png`, `public/logo.png`, иконки — `app/icon.png`, `app/apple-icon.png`.

## Контент

| Файл | Содержимое |
| --- | --- |
| `lib/content/steps.ts` | 6 этапов работы (главная, «Как это работает», HowTo-разметка) |
| `lib/content/faq.ts` | Вопросы-ответы (главная, `/faq`, FAQPage-разметка) |
| `lib/content/cars.ts` | Каталог моделей: ориентировочные цены в Бишкеке, двигатели, описания. Каждая модель — SEO-страница `/avtomobili/[slug]` |
| `lib/content/articles.ts` | Статьи блога `/blog/[slug]` (блог выключен флагом `features.blog`) |
| `lib/featured.ts` | Блок «Что мы привозим чаще всего» (редактируется в админке) |

## Заявки

Форма (`components/LeadForm.tsx`) отправляет данные в `POST /api/lead`. Если заданы `TELEGRAM_BOT_TOKEN` и
`TELEGRAM_CHAT_ID`, заявка приходит сообщением в Telegram; иначе — пишется в лог сервера.
